What this app does

  • Classifies one short WAV clip using the gate and ratio you selected.
  • Loads class order from the shipped labels.json; REJECT is a regular class.
  • Uses the shipped Gate2v6 preprocessing contract: mono, 16 kHz, 148×60 log-Mel, scalar train-only normalization.
  • Audio is processed in memory on this computer and discarded after inference; the app does not save or log it.

This is clip-level classification, not phone-sequence recognition or continuous streaming. Scores are uncalibrated model scores; no rejection threshold is applied.

Candidate models are not promoted or production-certified. No Raspberry Pi benchmark or real-microphone acceptance test has been done.
